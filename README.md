# My Skills

AI Agent Skill 集合仓库。每个 skill 是一个可复用的工作流定义，适用于支持 Skill 机制的 AI 编码助手（如 Claude Code、CodeBuddy 等）。

## 可用 Skills

### pr-merge-review

PR 合并风险审查与报告生成器：在其他分支提交 PR 合并入目标分支之前，对合并风险进行全面、详细的分析，最终产出结构化合并报告反馈给 PR 提交者。

**功能：**
- PR 上下文理解与变更意图分析
- AI 代码审查（正确性 / 安全性 / 性能 / 可维护性 / 架构 / 测试 / 生产就绪性）
- dev 分支功能合入完整性分析
- **target 分支功能完整性保护分析**（核心：合并后是否会破坏 master 现有功能/契约）
- 文本冲突 + 双向语义冲突 + 结构冲突 + 特殊文件冲突检测
- 风险严重程度分级（🔴 阻塞 / 🟠 严重 / 🟡 重要 / 🟢 小问题 / 💡 建议）
- 冲突解决方案设计（✅ AI 已给出确定方案 / ⚠️ AI 不确定，需人工确认）
- 验证与测试方案（含 target 功能回归验证）
- 结构化合并报告（merge_report.md），可直接复制到 PR 评论

**适用场景：**
- 团队代码审查 PR 是否可安全合并
- 评估 AI/vibe-coding 分支合并的风险
- 复杂分支合并前的冲突检测与方案设计
- 给 PR 提交者可操作的修复反馈

**使用方式：**
```
审查这个 PR 能不能合并到 main：feature/xxx
review this PR before merge
```

### json2md-feishu-publisher

将 JSON 格式文档转换为 Markdown 并发布到飞书文档。

**功能：**
- 自动解析 JSON 结构
- 生成格式化的 Markdown（支持表格、图片）
- 创建飞书云文档并分享给指定用户

**适用场景：**
- 将数据在飞书上展示
- 将 API 响应或数据导出发布到飞书
- 团队数据共享和协作

**使用方式：**
```
将这个 JSON 文件发布到飞书
```
